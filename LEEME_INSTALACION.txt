INSTALACIÓN EN EL REPOSITORIO DE PRUEBAS:
1. Descomprime el ZIP.
2. Sube los archivos en la RAÍZ de tu repositorio GitHub (como en la versión anterior).
3. Sube también la carpeta assets/ con sus seis imágenes, manteniendo la ruta assets/zeze-triste.png etc.
4. Confirma el commit. GitHub Pages publicará la nueva versión.
5. Recarga la página; si estás usando la PWA, ciérrala y vuelve a abrirla para actualizar el caché.
6. Antes de reemplazar una versión definitiva, prueba todos los ánimos y una rutina completa.

No se modificaron los archivos originales ni la página pública anterior.
